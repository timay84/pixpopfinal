## 力度与爆开

归一化压力为 0–1。向下输入大于水平分量的 0.9 倍时，向下分量转换成压力。压力 0.12–0.82 逐渐压扁；0.82–0.92 颤动；达到 0.92 并连续保持 120ms 后只爆开一次。0–0.12 秒从薄饼散开；0.12–1.05 秒主体消失；1.05–2.15 秒碎片聚回；1.25–2.3 秒本体重现。2.45 秒后完成重组。持续高压不重复触发，降到 20% 以下才重新解锁。鼠标/键盘的加压按钮用 1.6 秒长按模拟渐进压力。

## 单手柄协议

Web Serial：115200 baud，每行 JSON，例如 {"x":0.7,"y":0,"pressure":0.4}。X 左负右正，Y 上负下正；x/y 在 −1..1，pressure 在 0..1。也支持 x:0.7,y:0,pressure:0.4。p/pressed 可传布尔或数值；布尔 true 代表满压力，不能替代真正的模拟量测力。真实手柄是否有压力、方向或按钮通道取决于硬件，需要工程师校准和联调；本次没有接实体硬件测量。无有效数值的数据包会被丢弃。松手和断连走释放路径。

速度、连续反向、画圈和连续轻捏使用同一手柄的数据历史识别，不需要增加操作手柄。三种连续动作的识别优先级：轻捏星屑 > 上下反转扭转 > 左右反转分身 > 画圈。压力始终优先于这些效果。

## 渲染与交付

主舞台使用一个 WebGL 上下文，18 张卡片共享另一个离屏 WebGL 上下文，再复制到各自 2D 画布。每张卡片都是同一幽灵网格的实时渲染，屏外停止绘制，卡片约 15fps，主体跟随显示刷新率。低端手机仍需实机压测。系统减少动画偏好会降低位移、拖尾和爆开幅度。

单动作网页：/?solo=1&motion=burst（替换 motion 为状态 ID）。构建后也提供 motions/01-idle.html 等 18 个独立入口。界面支持暂停、重播、透明 PNG 导出和单动作视频导出。静态模型 GLB 不含烘焙动作，动画在 lib/motion.ts 与 lib/ghost-scene.ts 中。

素材包每个编号包含 WebM、透明 PNG、单页 HTML、反馈说明 Markdown。WebM 为有底色的 960×640 视频；PNG 保留透明背景。素材总览 index.html 可直接在本机打开。
